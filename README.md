# AtnLyze WAF

AtnLyze is a transformer-based, end-to-end Web Application Firewall (WAF) designed to detect malicious HTTP requests using attention-based deep learning models.

## Project Goals
- Learn normal and malicious web traffic patterns
- Detect known and novel attacks
- Provide real-time inference via API
- Be modular, extensible, and production-oriented

## Structure

- src/ → Core application code
- tests/ → Unit and integration tests
- data/ → Datasets (ignored except samples)
- notebooks/ → Exploration & analysis
- scripts/ → CLI scripts
- docs/ → Documentation
